# Data source and handling

Source: Human Resources Data Set by Rich Huebner on Kaggle  
https://www.kaggle.com/datasets/rhuebner/human-resources-data-set

The source dataset is described as fictional. Review the current license and attribution terms on the source page before redistributing any dataset files.

The repository should not include the raw CSV unless redistribution is permitted. Before publishing the Excel workbook, create a sanitized portfolio copy that removes unnecessary personal identifiers such as employee names, dates of birth, ZIP codes, and any other sensitive or identifying fields. Keep the original source file locally if needed for reference.

The workbook's analysis currently covers 311 employee records. The `Data/` directory intentionally contains documentation only.
